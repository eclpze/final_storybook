# STORYBOOK

Мобильное приложение на **Flutter / Dart** с отображением ключевых элементов UIKIT.
## Технологии

- **Flutter**
- **Dart**
- Android Studio

## Запуск проекта

1. Установите [Flutter SDK](https://docs.flutter.dev/get-started/install).
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/eclpze/final_storybook.git
   cd bank_app
   ```
3. Установите зависимости:
   ```bash
   flutter pub get
   ```
4. Запустите приложение на эмуляторе или устройстве:
   ```bash
   flutter run
   ```
